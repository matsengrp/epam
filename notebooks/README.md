## Generate dataframes and tables

The dataframes and tables are generated by the following scripts:

| code | description
|---|---|
| `write_dfs_for_plots.py`</br>`write_gcreplay_dfs_for_plots.py` | Write various dataframes with per site information such as site substitution probability or conditional substitution probability for models on human repertoire or Replay data sets. |
| `plot_model_oe_all.py`</br>`plot_gcreplay_model_oe_all.py` | Compute overall performance metrics (e.g. `tables/tang_metrics.csv`) for models on human repertoire or Replay data sets. Also, generates individual observed-vs-expected plots per model. |
| `write_conserved_csv.py` | Compute expected number of substitutions at known conserved sites for the Tang et al. data set (`tables/tang_conserved.csv`). |
| `write_overlap_csv.py`</br>`write_gcreplay_overlap_csv.py` | Compute overlap metric overall and in each CDR/FWR region for Tang et al. or Replay data set. |
| `write_rprec_csv.py`</br>`write_gcreplay_rprec_csv.py` | Compute R-precision overall and in each CDR/FWR region for Tang et al. or Replay data set. |
| `write_subacc_csv.py`</br>`write_gcreplay_subacc_csv.py` | Compute substitution accuracy overall and in each CDR/FWR region for Tang et al. or Replay data set. |
| `write_cspperp_csv.py`</br>`write_gcreplay_cspperp_csv.py` | Compute CSP perplexity overall and in each CDR/FWR region for Tang et al. or Replay data set. |
| `eval_per_mut_count.py` | Compute per PCP quantities to evaluate R-precision stratified by number of substitutions for Thrifty-prod on Tang et al. and ReplaySHM+DMS on Replay data set. |
| `plot_model_oe_all_nsubs.py` | Compute overall performance metrics stratified by number of substitutions per PCP (e.g. `tables/tang_nsubs_metrics.csv`) for models on human repertoire data sets. Also, generates individual observed-vs-expected plots per model and substitution count. |
| `gcreplay_esm.py` | Evaluate amino acid probabilities on the Replay naive sequence for all five ESM-1v models (e.g. `dataframes/replay_igh_igk_esm5.hdf5`). |

To run these scripts, download and extract in this directory the following archives from [https://doi.org/10.5281/zenodo.17353498](https://zenodo.org/records/17353498):

- `pcps.tar.gz`
- `aaprobs.tar.gz`
